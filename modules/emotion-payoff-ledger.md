# 情绪欠账与兑现账本

## 目标

跟踪读者被压了什么、正在等待什么，以及故事最终用什么真实改变偿还。

## 情绪债记录

```text
债务编号：
第一次发生的位置：
读者被压的具体内容：
造成者：
造成者是否明知：
主角当时为什么不能反击 / 离开：
读者自然期待的结果：
后续如何加码：
部分偿还：
最终偿还：
偿还付出的成本：
兑现后真实改变：
未完全偿还的余波：
```

## 什么算真实兑现

至少改变一项：

- 权力归属。
- 关系状态。
- 选择权。
- 利益、钱、工作、身份或名誉。
- 谁必须承担代价。
- 谁终于被看见、相信或放弃。
- 主角对自己底线的选择。

以下单独出现不算兑现：

- 众人震惊。
- 反派脸色惨白。
- 主角说一段漂亮话。
- 对方道歉或后悔。
- 作者宣布“她终于赢了”。
- 临时出现更有权势的人替主角解决。

## 爽点验证

```text
前面具体压了什么？
读者等了多久、等的是什么？
主角为反击准备或牺牲了什么？
反击使用的证据、能力或规则是否提前出现？
谁失去了什么？
局势是否不可逆地改变？
爽后产生什么新问题或余波？
```

无压迫、无等待、无成本、无状态变化的“爽点”只是表演。

## 情绪曲线

不按固定字数硬塞奖励。按读者当前问题检查：

```text
压迫 → 尝试 → 小失败 / 带代价的小成功
→ 压力升级 → 部分偿还 → 更难选择
→ 最终兑现 → 余波
```

连续压迫却不给希望，读者会麻木；连续兑现而不建立新代价，读者会觉得廉价。

## 结局检查

结局优先偿还最早、最重、最私人化的那笔债。若故意不偿还，必须说明作品想留下的痛感与可能造成的读者失望，不能假装已经完成。
