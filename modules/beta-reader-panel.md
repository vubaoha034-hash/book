# 独立读者面板模块

## 职责

模拟多个阅读目的不同的真实读者，按正文顺序第一次阅读，记录哪里被吸引、哪里困惑、哪里开始滑读、哪里情绪失效、哪里不再相信故事。

此模块提供的是阅读反应，不是编辑方案。读者可以准确指出“这里让我离开”，但不负责告诉作者唯一正确的改法。

## 默认读者席位

根据题材可调整，但默认保留四种互补视角：

### 1. 手机沉浸读者

最关心：

- 是否想继续翻页
- 情节是否持续变化
- 哪里开始滑读
- 情绪是否直接有效
- 第一处放下手机的位置

### 2. 类型承诺读者

最关心：

- 题材承诺是否清楚
- 读者期待的核心体验是否兑现
- 套路是否提供新变化
- 反转、悬疑、爱情、爽感或恐惧是否公平

### 3. 人物情感读者

最关心：

- 是否理解人物为何这样做
- 是否愿意站在人物一边
- 关系变化是否可信
- 哪个动作或选择真正击中情绪
- 哪里只是在要求读者感动

### 4. 怀疑与逻辑读者

最关心：

- 人物是否降智
- 是否存在更简单办法
- 时间、空间、规则和物件是否合理
- 转折是否依赖巧合或新增设定
- 哪一刻开始不再相信故事

必要时可增加“语言读者”，但不得让所有席位都从同一套审稿清单出发。

## 独立性规则

1. 每个读者先完成完整第一反应，之后才能看其他人的报告。
2. 不允许后一个读者回应、赞同或复述前一个读者。
3. 不允许为了形成共识，回头修改已经锁定的个人反应。
4. 汇总阶段保留分歧，不用平均分消灭不同口味。
5. 当环境支持并行子代理时，每个读者使用独立上下文。
6. 单上下文运行时，也必须先依次锁定四份报告，再做汇总。

## 阅读方式

按正文顺序前进，不提前读取结局解释。

每个读者记录：

- 第一次被吸引的位置
- 当前持有的问题
- 对下一步的预测
- 第一次滑读的位置
- 第一次困惑的位置
- 第一次情绪击中或落空的位置
- 第一次不相信人物或规则的位置
- 最可能停止阅读的位置
- 读完后真正记住的三件事

## 反应类别

### 靠近

出现新问题、风险、选择、关系变化、鲜明细节或情绪兑现，注意力增强。

### 保持

故事仍然清楚，但没有明显增强或减弱。

### 滑读

读者加快速度，想跳过重复、解释、过场或无功能描写。

### 困惑

读者不知道谁在做什么、为什么这样做、规则是什么，或信息被不公平隐藏。

### 失信

人物、巧合、设定、时间或因果不再可信。

### 离开

读者已经没有足够问题、情绪或承诺支撑继续阅读。

## 汇总规则

汇总不是计算平均分，而是看：

- 多个独立读者是否在同一位置失去注意力。
- 同一问题是否同时伤害不同阅读目标。
- 单个读者是否发现一个足以破坏全篇的高影响问题。
- 哪些反应只是个人口味。
- 哪些优点是多个读者共同感受到的，修改时必须保护。

优先级判断：

```text
多人同位置 + 高影响 = 必须处理
单人发现确定性逻辑断裂 = 必须核查
单人口味偏好 = 记录但不强改
多人共同记住的优点 = 修改保护项
```

## 输出模板

```md
# 独立读者面板

## 阅读范围与目标读者

## 读者一：手机沉浸读者
### 总体感受
### 阅读轨迹
### 滑读点
### 离开点
### 读完记住的内容

## 读者二：类型承诺读者

## 读者三：人物情感读者

## 读者四：怀疑与逻辑读者

## 汇总
### 多人共同命中的问题
### 高影响单点问题
### 仅属口味的分歧
### 必须保护的有效部分
### 第一修改优先级
```

## 禁止事项

- 不给每个读者安排夸张人设，避免四个角色最后说同样的话。
- 不写“总体不错但……”式安慰。
- 不直接替作者重写。
- 不根据作者的期待调整反应。
- 不把读者建议当作命令；读者反应是证据，修法由后续编辑阶段决定。
