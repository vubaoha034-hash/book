# 行文精修与去 AI 味模块

## 职责

在主线、因果、人物动机、连续性、V3-G6D 和场景结构已经稳定后，对正文进行逐句诊断与最小必要修改。

此模块只改变“怎么说”，不暗中改变“发生了什么”。发现结构或逻辑问题必须退回对应阶段。

## 使用前置条件

- 一句话主线稳定。
- 关键人物选择成立。
- 没有阻断级连续性冲突。
- `V3-G6D = PASS` 或其开放项已被明确隔离、禁止在本轮靠润色掩盖。
- 场景顺序、高潮和结局方向稳定。

## Pattern-first：先找习惯，再找句子

不要把全文逐句标红。先识别 2—5 个反复出现、最伤读感的习惯，再引用典型位置。

### 1. 过滤与距离失控

“他看见 / 她感觉到 / 我意识到”等不是绝对错误；只有在叙述需要更近而过滤词把读者隔开时处理。

### 2. 解释重复

动作或台词已经表达情绪，后面又解释，再总结意义。优先删除重复解释。

### 3. 抽象情绪与万能反应

警惕心口一沉、眼神复杂、深吸一口气、手指收紧、嘴角勾起等高频万能反应。没有人物/场景功能时直接删，不机械替换。

### 4. 句长单一

检查连续句子是否同长、是否把完整动作切成电报、复杂判断是否被过度切碎。句长跟随场景任务，不服从固定比例。

### 5. 说明书式对话

局部嘴替真值由 G6D 先判。行文层只处理已经有合法 scene/epistemic payload 但表达仍过满、重复、书面化的问题。

特别注意：

```text
人物知道 X
!=
人物知道外界也知道 X
```

不要为了“去说明感”把新的 public/exposure/risk 信息一并删掉。

### 6. 声音漂移

检查叙述者是否突然变作者评论、所有人物是否共用同样词汇句式、愤怒/亲密/恐惧时语言是否仍完全一样。

### 7. 假高级与意义尾巴

处理重复使用的命运、宿命、齿轮、篇章、仿佛、某种、章末升华和替读者总结的尾巴。以功能判断，不用词表机械删除。

### 8. 监控摄像头动作

合并无功能的拿起、放下、转身、走到、伸手。只保留改变视角、选择、压力或信息的动作。

### 9. Dialogue Pattern Family Ledger

读取：

```text
modules/dialogue-pattern-family-density.md
templates/dialogue-pattern-family-audit-template.md
```

先从全文收集可能属于同一**对话机器**的实例，再判断 family，而不是看到单句就删。

每个实例至少记录：

```text
location
speakers / relationship
scene_task
cadence_skeleton
current_object_or_task_anchor
shared_history_anchor
independent_local_goal
portable_to_unrelated_characters
local_G6D_verdict
```

每个 family 再比较：

- 是否跨多个分离场景；
- 是否跨不同人物/关系；
- cadence 和 reveal timing 是否高度相似；
- 是否缺乏人物/场景特异性；
- 是否让不同人物听起来像同一个模型；
- 是否存在真正的机制变化、后果变化。

高风险使用：

`DIALOGUE_TEMPLATE_FAMILY_DENSITY_RISK`

当前不冻结统一“出现 N 次即失败”的数字阈值。

同一人物的固定口头习惯、同一关系的 running joke、依赖特定物件/旧账的笑话可 PASS/HOLD。

## 最小修改原则

1. 能删一句，不重写一段。
2. 能改最通用的一处，不动最有角色特异性的实例。
3. 一个 family 中优先保护最强实例，处理最可移植的重复实例。
4. 可以改变应答策略：直接答、沉默、打断、只答一半、行动、误听、拒绝，而不是换一套新包袱。
5. 不新增不存在的道具、秘密或人物关系。
6. 不为去 AI 故意造错别字、病句和随机标点。
7. 修改对白后复核局部 G6D，确认知识、时间、关系和信息载体未被破坏。

## 行文标记格式

```text
原句/位置：
问题类型：
pattern_family_id（如适用）：
为什么伤读感：
必须保护的事实/关系：
修改方向：
是否需要直接修改：是 / 否 / 退回结构阶段
```

## 最终检查

- 是否还有作者替人物总结。
- 是否把动作后的同义心理解释删掉。
- 是否保留人物独有的小动作和说话方式。
- 是否存在跨场景的同一 dialogue cadence family。
- 是否有人物声音被同一套反问/包袱/回避机器覆盖。
- 是否因为过度精简损失必要心理、情绪余波或 epistemic 信息。
- 是否用固定数量规则替代了真实 family 证据；如有，撤销。

## 禁止事项

- 不在结构未定时精修全文。
- 不把所有心理改成动作。
- 不把所有句子压短。
- 不用统一口语词把不同人物改成同一个人。
- 不以“更顺”为唯一目标。
- 不把单个 locally plausible joke 因为可删就自动判 G6D 错。
