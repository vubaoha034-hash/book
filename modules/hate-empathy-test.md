# 恨感与共情测试

## 目标

让读者的情绪来自人物选择，而不是标签、悲惨履历或作者命令。

## 主角共情证据

至少建立四层：

1. **普通欲望**：保住工作、被家人尊重、让孩子过得好、活下去、体面地离开。
2. **真实缺点**：嘴硬、怕丢脸、自私、讨好、逃避、嫉妒、控制欲或错误判断。
3. **可理解原因**：正文能让读者理解这种缺点如何形成、当下如何保护过他。
4. **有代价选择**：他明明害怕，仍主动做一件会失去钱、关系、安全、身份或退路的事。

检查：

```text
我为什么理解他？
我哪里不赞同他？
他如果什么都不做会怎样？
他主动选择了什么？
他付出了什么？
选择后局势如何改变？
```

只有悲惨、善良和被欺负，不足以形成共情。

## 伤害者恨感证据

至少满足：

```text
他有不伤害的可选方案；
他仍主动选择伤害；
伤害给他带来利益、面子、安全感或控制权；
受害者或他人已经提醒；
他推责、否认、倒打一耙或继续加码；
后果与其伤害方式相对应。
```

强度来自“明知仍做”，不是来自提高骂人音量。

## 不要误用立体化

理解伤害者的动机，不等于替他开脱。可以写出他的恐惧、家庭、损失和自我辩护，但必须保留：

- 他拥有选择。
- 他做出选择。
- 别人承担了后果。
- 他是否愿意承担自己的后果。

## 对应后果

后果最好击中他用来伤人的东西：

- 用舆论羞辱别人，最终失去话语权或可信度。
- 用钱控制家人，最终钱无法买回关系。
- 用身份压人，最终身份成为公开证据。
- 用沉默逃责，最终必须在无法回避的场合选择。

这不是机械报应。作品也可以让坏人逃脱，但需让读者看见这种未偿还会造成什么，而不是用一句“现实就是如此”草草结束。

## 场景测试

每个关键冲突都问：

```text
双方分别想保住什么？
两个目标为何不能同时成立？
谁有更多权力？
谁先越过边界？
谁获得了即时利益？
谁承担即时损失？
主角做了什么选择，而不是只承受？
```
