# Spatial Causality, Pacing Compression, and Dialogue Voice — Developmental

Purpose: prevent a manuscript from passing because individual scenes are locally coherent while the actual reader experiences spatial disbelief, serial-stop pacing drag, or a single dialogue cadence across characters.

## Core non-equivalences

```text
LOCAL_SCENE_FUNCTION != GOOD_GLOBAL_PACING
DISTINCT_SCENE_ENGINE != FAST_ENOUGH_READING EXPERIENCE
ACTION_AROUND_DIALOGUE != DISTINCT_CHARACTER_VOICE
BARRIER_MENTIONED != BARRIER_CREDIBLE
EXIT_AVAILABLE != EXIT_CAUSALLY_USABLE
MORE_CHECKPOINTS != MORE_PROPULSION
MORE_EXPLANATION != MORE_CLARITY
```

## 1. Spatial causality / blocking ledger

For every high-pressure scene, explicitly track:
- entrances and exits;
- who occupies or observes each route;
- line of sight / hearing where material;
- crowd intent and whether it is unified or divided;
- physical barriers;
- legal/social/tactical barriers;
- what changes before a blocked route becomes usable.

Hard rule:
If text establishes `rear alley has people`, `door is surrounded`, `guards control gate`, or equivalent, characters may not simply use that route later unless the blocker is shown to move, split, be distracted, be bypassed, be deceived, or be unable/unwilling to intervene for a legible reason.

A door does not plausibly stop a hostile group by itself. If a crowd does not storm a room, show why: mixed motives, fear of law, shop owner/community restraint, physical barricade, armed defense, narrow access, internal disagreement, or another specific cause.

## 2. Serial-checkpoint pacing failure

Warning pattern:

```text
move -> stop -> clue/explanation -> move
-> hide -> clue/explanation -> move
-> new stop -> relationship talk -> move
-> treatment stop -> decision talk -> move
```

Each scene can be individually valid and the manuscript can still be slow.

Audit adjacent scenes for MERGE / CUT / REORDER:
- If two consecutive scenes mostly advance the same route objective, merge unless each creates an irreversible different choice.
- If a travel stop exists mainly to deliver one clue, try moving the clue into a scene already carrying danger/relationship pressure.
- If injury processing repeats without changing the next decision, compress it.
- If exposition can occur during an already necessary action scene, do not create a separate stop for it.
- A scene is not protected because it has a unique prop or technically distinct micro-engine.

Global question:
`How many times does the reader have to stop before the main objective meaningfully changes?`

## 3. Dialogue voice separation

Distinct voice is NOT catchphrases or dialect decoration.

For each major character define:
- what they answer directly;
- what they refuse to answer;
- whether they reason through evidence, emotion, status, action, or silence;
- how they behave when cornered;
- what they notice first;
- how they attack or defend in conversation;
- what relationship changes their speech.

Hard rule:
Do not let multiple characters repeatedly share:
`question -> exact short answer -> follow-up -> exact short answer`.

Even with action beats, this remains the same dialogue engine if information is still transferred turn-by-turn.

Preferred alternatives:
- inference before question;
- refusal;
- correction of the premise rather than answer;
- answer embedded in action;
- one person speaks past the offered question;
- evidence makes the answer unnecessary;
- delayed answer after consequence;
- competing priorities prevent completion.

Formal testimony/interrogation may support cleaner Q&A, but ordinary relationship, travel, conflict and suspense scenes should not default to institutional interview rhythm.

## 4. Clarity test

For each scene, a fresh reader should be able to answer without rereading:
1. Where are the principal characters?
2. What physically prevents the obvious escape/attack/entry?
3. Who wants what right now?
4. What changed by the end?

If the scene requires author explanation outside the prose to answer these, staging is not sufficiently clear.

## 5. Pilot-before-scale rule

If actual human rejection includes spatial confusion + severe pacing drag + recurring dialogue cadence:
- do NOT immediately rewrite the whole manuscript;
- first create a compressed first-act pilot covering the earliest disengagement zone;
- obtain actual-human acceptance of clarity, pace and voice;
- only then authorize full-manuscript reconstruction.
