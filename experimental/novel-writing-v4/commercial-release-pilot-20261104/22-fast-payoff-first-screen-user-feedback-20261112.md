# 第一集短试稿｜两枚灵钱买走未来神兽

上一世，韩追靠一条镇岳玄龙成了九宗第一御兽师。只有许砚知道，那条威震天下的神龙，最初是兽市里一只没人要的断尾土蜥。

重生回选兽当天，许砚第一件事，就是把两枚灵钱拍在摊子上：“这只，我要了。”

于肃看得直乐：“你穷疯了？这东西连尾巴都长不齐！”许砚没理他，领了买卖票，完成初契，抱着小蜥去了后山。

他记得，前世韩追的神兽第一次长出龙纹，就在那口废井里。许砚从井底石缝敲下三粒不起眼的黑砂，抹在幼蜥颈后的灰斑上。旧甲裂开，竟露出一道金色龙纹！

兽契里，一股地气冲进丹田。许砚卡了许久的瓶颈当场松动——**练气五层！**

小蜥很快收了龙纹，重新缩进袖子，看上去仍是那副半死不活的模样。许砚带它回兽坊登记试斗，于肃又笑了，当众把十枚灵钱押在桌上：“它能挡住我的铁牙犬一招，这钱归你。”

许砚低头：“于师兄，说话算话。”

铁牙犬一扑上来，许砚只说了一个字：“挡。”小蜥猛地抬头，龙纹一闪。砰的一声，铁牙犬被撞得倒飞出去，摔下了试兽台。

场边没人笑了。许砚也不解释，伸手收走那十枚灵钱。

两枚钱买到未来神兽，当天突破一层修为，还白赚十枚。这笔账，怎么看都不亏。

傍晚，韩追赶到摊前：“婶子，早上那只断尾蜥呢？”

陶婶朝试兽台一指：“许砚买走了，刚才还赢了于肃十枚灵钱。”

韩追愣住。许砚却已抱着幼蜥走远——**原本属于韩追的逆天机缘，如今换了主人。**
