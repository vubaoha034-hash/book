## 2. 最重要的纠偏：事件规模 ≠ 一定要宏大

此前的 `THEME_AND_EVENT_SCALE_FAIL` 很容易被误修成“以后都写死人、战争、末日”。

这同样是错的。

从当前头部样本看，真正关键的是：

> **未来状态空间是否足够大。**

《1984：从川菜馆开始》并不靠世界毁灭；它靠店铺、食材、现金流、顾客、口碑、供应链、竞争和家庭关系持续记账。

《今晚还听么》也不是大事件；它靠一个可重复的匿名互动仪式，让关注、身份信息、现实接触、公开性与关系承诺逐级变化。

所以“值得读”的规模，本质不是爆炸半径，而是：

1. 一场结束后还有没有结构性余波；
2. 成功是否会制造下一层问题；
3. 是否有多个独立压力轴；
4. 人物能否进入新的状态，而不是回到原点；
5. 同一个发动机能否长出真正不同的场面。

反过来，一次口角哪怕写得再尖锐、一次伦理选择哪怕再精巧，只要说清、离开、拒绝、道歉后就基本结算，它仍然是“小事”。

## 4. 现在真正热门的小说，最先在卖什么承诺？

不是简单的“玄幻”“重生”“离婚”“系统”“权谋”。

更稳定的第一层承诺有六种：

1. **世界已经变了，而且回不去。**
   读者先问“新规则到底会把人逼到哪里”。

2. **这个人的人生位置已经变了，而且旧生活无法原样恢复。**
   重生、亡国、出狱、身份死亡、身体共享、神器融合都属于这类。

3. **我能看见一条可积累的进度轴。**
   钱、修为、店铺、军队、基地、领地、职业位置、关系承诺都可以。

4. **这里有一个不能一次解释完的秘密。**
   身份、世界边界、历史、阵营真实立场、规则来源，答案会改变行动。

5. **人物被锁进一个长期结构，而不是一次争吵。**
   婚姻、共同身体、君臣、直播仪式、国家机构、家族、战争、资源依赖。

6. **当前胜利不会清零故事，而会扩大下一层问题。**
   赢得越多，地图、责任、敌人、资源需求、公开性或关系承诺越大。

这就是“读者为什么愿意再给 30 分钟”的核心：**读者能提前感觉到，第一场只是入口，不是全部。**

## 5. 哪些核心设定天然会长出大量新局面？

本轮得到 8 个真正有样本支撑的强发动机族。

### ENGINE-01 不可逆世界规则 / 高概念秩序改写

不是“有个新奇设定”，而是一个规则持续重写生存、资源、制度与认知。

代表机制：永久异常世界、现代与超凡重叠、末世生产规则、可重复跨界。

### ENGINE-02 不可逆身份 / 命运转位

身份、时间线、身体、生命状态或社会记录已经变了，角色不能退回旧位。

它的价值在于：新身份会不断撞上旧关系和旧责任。

### ENGINE-03 生存—资源—建设 / 成长闭环

资源要获得、消耗、转换、再投资。

强点不是“主角得到东西”，而是**成功会扩大资产，也扩大维护成本和责任**。

### ENGINE-04 强制度 / 阶层 / 利益网络

国家、家族、宫廷、殖民秩序、婚姻、职业或阶层拥有真实的奖惩能力。

人物无法靠一句“我不同意”退出整个系统。

### ENGINE-05 谜团 / 秘密 / 规则揭示链

不是单个悬念，而是分层信息结构。

回答 A 会打开 B，B 的答案又会迫使人物重新理解前面的行动。

### ENGINE-06 持续升级的关系结构

小场面完全可以有小说性，前提是关系状态会累积。

可累积变量包括：

- 信息知道多少；
- 是否能退出；
- 谁欠谁；
- 谁公开谁；
- 权力差；
- 承诺等级；
- 共同资产 / 共同秘密；
- 职业或家庭角色。

### ENGINE-07 战争 / 竞争 / 晋升 / 领地扩张

有明确外部进度轴。

真正有效的升级不是“下一个敌人更强”，而是成功后：

- 地图更大；
- 资源更多；
- 敌人更多；
- 责任更重；
- 参与者更多；
- 失败损失更高。

### ENGINE-08 强制机制 / 敌对系统 / 互相需要的契约

角色无法忽视一个持续运转的机制，必须交易、反制、钻漏洞或共同解决缺口。

一次漂亮选择不会把机制关掉。

## 6. 开场第一屏 / 第一场为什么值得继续读？

本研究没有假装逐章冷读全部 23 部，所以这里的“开场发动机”以官方简介、公开作品页与可见首发信息为证据边界。

强开场通常做的不是“马上来一个大反转”，而是完成至少一件事：

1. **把旧世界关掉。**
   太阳不再升起、人物已死又回来、亡国、入狱后归来、被埋并融合异物。

2. **把角色锁进一个会继续运转的结构。**
   接手破产店、共享身体、绑定系统、进入宫廷、形成交易婚姻、建立重复匿名联系。

3. **让第一次选择改变故事参与者。**
   例如私人系统危机被上交后，故事从“人对系统”变成“组织对系统”。

4. **给出近端回报，同时留下远端问题。**
   主角先获得逃生、能力、资源或关系变化，但能力来源、身份、政治后果仍未结算。

5. **让读者看见第二场和第五场不是同一场的复制。**
   有资源问题、身份问题、制度问题、关系问题、信息问题等不同压力可轮换。

## 7. 什么是“角色性”但没有“小说性”？

以下类型以前很容易在我们的机器门里通过，因为它们特别容易体现“这个人会怎么选”：

- 隐私还是自证；
- 要不要替别人解释；
- 熟人替我回答；
- 是否当众纠正；
- 是否保全面子；
- 一个小误会该不该澄清；
- 一句冒犯后怎么回；
- 一个体面但难受的伦理选择。

这些可以证明人物性格，却通常有四个共同问题：

1. **去掉名字后，核心仍是一个通用生活题。**
2. **一句解释 / 拒绝 / 离开就能基本结束。**
3. **后续只能把同类社交摩擦换场景重复。**
4. **解决第一场后没有新的资源、关系、身份、制度或谜团状态。**

所以：

> **人物很真实、很拧巴、很特别，只能作为小说发动机上的人物纹理，不能替代发动机本身。**

# 8. READER_ATTENTION_WORTHINESS V1 前置门

位置：

> **任何新的 Phase408 candidate 生成之前。**
>
> 先过本门，再进入 protagonist-specificity / 罗钧特异性 / 角色选择攻击审查。

未来任何候选必须回答以下六项。

## RAW-01 THIRTY_MINUTE_EXCHANGE

**问题：**只看一句核心，为什么读者愿意把接下来 30 分钟交给它？

PASS 必须说清一个会持续变化的价值：
世界、命运、资源、关系、谜团、长期目标至少一个。

“因为想看罗钧会怎么选”不算。

## RAW-02 DE_NAMED_ENGINE_DURABILITY

**问题：**去掉名字、口头禅、职业标签和性格描述后，主题本身还会产出局面吗？

若去名后只剩：

- 一次尴尬；
- 一次边界问题；
- 一次伦理选择；
- 一次误解；

则 BLOCK。

## RAW-03 PRESSURE_DIVERSITY_5

核心冲突必须自然支持至少 **5 类结构不同的压力**。

可计入：

- 生存；
- 资源；
- 身份；
- 制度；
- 关系；
- 信息；
- 时间；
- 职业 / 法律；
- 敌对势力；
- 责任；
- 领地；
- 公开性。

同一个“别人让我难堪”换五个人、五个场景，只算 **1 类**。

## RAW-04 DURABLE_STRUCTURAL_ANCHOR

至少要有一个真正约束多场的结构锚：

- 不可逆变化；
- 持续关系结构；
- 世界规则；
- 利益 / 资源系统；
- 谜团 / 揭示链；
- 长期欲望 / 使命；
- 强制契约。

“角色性格很特别”不在此列。

## RAW-05 ESCALATION_AXES

至少能沿 **3 个不同轴**升级：

- 后果；
- 空间；
- 敌手；
- 信息；
- 责任；
- 资源；
- 关系承诺；
- 社会位置 / 权力。

只有“下一次更尴尬、更生气、更难解释”，FAIL。

## RAW-06 POST_OPENING_RESIDUE

第一场事件就算解决，主发动机也必须继续存在。

要能回答：

> 当场问题解决之后，**什么仍然没有解决，而且会逼出下一种不同的问题？**

回答不出来，BLOCK。

## 9. 默认 HARD BLOCK

命中任意一项，不得再用“人物独特”救回来：

1. 只是小尴尬、一次口角、一次体面选择，没有立即打开更大结构；
2. 是一个一次性伦理 decision puzzle；
3. 一句解释、道歉、离开、拉黑、拒绝或澄清即可低成本消解；
4. 唯一卖点是人物很拧巴 / 很真实 / 反应很特别；
5. 无法自然列出 5 类不同压力，只能重复同一种社交摩擦。

**PASS 规则：RAW-01～RAW-06 全部 PASS，且无 HARD BLOCK。**

## 11. 为什么我们之前总产出“合理但不值得看”的小事？

不是因为系统不懂逻辑。

恰恰相反，是因为它太擅长优化一种**容易审计的局部问题**：

> “这个人物下一步做什么，才能证明他与别人不同？”

隐私、自证、体面、熟人边界、是否解释，这类事件有三个机器优势：

1. 因果边界清楚；
2. 很容易设计一个独特选择；
3. 很容易做 swap-protagonist / character-specificity 攻击。

于是系统把“人物专属”误当成“小说值得读”。

但读者买的不是一个漂亮选择。

读者买的是：

> **做完这个选择以后，世界、关系、资源、身份、谜团还有什么在继续运转。**

因此，正确顺序必须改成：

```text
READER_ATTENTION_WORTHINESS
→ THEME / EVENT ENGINE
→ protagonist-specificity
→ character choice
→ 后续因果与正文
```

而不是：

```text
先找一个能体现人物差异的小事
→ 再努力证明它值得读
```

## 12. 本轮冻结结论

1. 当前热门作品的共同点不是某个单独题材，而是拥有**持续产出未来状态的结构**。
