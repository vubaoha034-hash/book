# MICROCRAFT Regression Label Calibration V1

## Status

Phase 344 calibration artifact. This document does **not** modify the private manuscript and does not retroactively change any historical Fresh Attempt result.

## Why calibration became necessary

The original three manuscript seed failures were useful for discovering missing microcraft coverage, but repeated correctly bound fresh audits produced unstable classifications around two of the three labels:

- the local semantic-time chain was repeatedly and independently rediscovered;
- the public-background bundle alternated between FAIL and PASS under valid fresh machinery;
- the single rhetorical-ladder example alternated between FAIL and PASS while stronger anti-template machinery began flagging additional ordinary jokes that may be locally natural.

At that point, continuing to harden the evaluator until it reproduced all three preferred labels would become benchmark overfitting. The correct response is to test the **labels**, not force the model to agree with them.

## Three-book contrastive evidence

The private three-book Scene-to-Speech evidence contains 90 raw-derived abstract samples (30 per book). It supports the original core principles:

- important speech usually has a scene source: observation, evidence, task, relationship pressure, silence, object state, misunderstanding or new information;
- silence, delay, interruption and partial answers are legitimate;
- exposition works when carried by interrogation, negotiation, testimony, teaching, evidence, task need or relationship action;
- banter can be generated by current objects, shared history, threat re-evaluation, embarrassment or relationship permissions;
- not every socially natural line has to change the external task state.

The evidence therefore supports Scene-to-Speech grounding, but does **not** support the stronger rule that every removable joke is a hard logic failure or that every repeated object-level fact is author-mouthpiece prose.

## Calibration 1 — Epistemic scope

Dialogue audits must distinguish levels of knowledge.

A proposition can appear at multiple epistemic levels:

1. `OBJECT_FACT`: event X is true.
2. `LISTENER_KNOWS_OBJECT_FACT`: the listener knows X.
3. `PUBLIC_KNOWLEDGE_OF_OBJECT_FACT`: outsiders/public rumor know X.
4. `REPORTED_RUMOR_CONTENT`: the speaker reports what outsiders are saying about X.
5. `EVIDENCE_OF_EXPOSURE_OR_SPREAD`: arrivals, reactions or behavior show the rumor is consequential.
6. `ACTIONABLE_RISK_FROM_PUBLIC_KNOWLEDGE`: public awareness changes safety, secrecy or strategy.

A listener can know X while not knowing that outsiders know X. Therefore a report such as “people outside are saying X about you” cannot be reduced to “the listener already knows X”.

### Consequence for the former MC-R002 hard label

The old mandatory hard label is retired.

A compact line that repeats an event and the listener's own role may still be scene-grounded if those facts are embedded inside a new report about rumor spread, exposure, pursuit or public knowledge. It may remain wordy, too explicit or insufficiently economical; that is not automatically the same as `AUTHOR_INFORMATION_MOUTHPIECE_FAIL`.

Hard mouthpiece failure remains valid when there is no distinct epistemic payload, no warning/reframing/accusation/negotiation purpose, and the listener simply receives shared setup for the reader's benefit.

## Calibration 2 — Local banter versus pattern-family density

A locally removable joke is not automatically a hard G6D failure.

Single exchanges can be credible because of:

- nervous deflection;
- embarrassment;
- status or face-saving pressure;
- affection or teasing permission;
- current object/task;
- shared history;
- deliberate withholding.

The stronger AI-smell signal is **cross-scene recurrence of the same portable conversational machine**.

Examples of the family-level risk include repeated use across unrelated scenes of:

`question -> clever retort -> induced follow-up -> punchline`

when:

- different characters use nearly the same cadence;
- the jokes depend weakly on their individual history or current task;
- the same timing and reversal recur across separated scenes;
- removing the scaffold repeatedly leaves the same information underneath;
- character voices converge toward one writer/model voice.

This is best treated as `DIALOGUE_TEMPLATE_FAMILY_DENSITY_RISK` in the style/de-AI evidence layer unless a particular local exchange independently lacks any credible scene grounding and materially damages dialogue truthfulness.

### Consequence for the former MC-R003 hard label

The old mandatory single-instance hard label is retired.

The original instance remains a useful **style-risk seed** because it resembles a portable model-generated cadence. But its local context may support fear/deflection/relationship behavior. The system should therefore ask whether this conversational family recurs across the manuscript, not demand that this one instance must always be labeled a G6D blocker.

## What remains hard

`MC-R001 / TEMPORAL_SEMANTIC_CHAIN_FAIL` remains a hard regression. It is a deterministic semantic contradiction, independent of taste or style preference.

Other hard G6D categories also remain available when independently evidenced, including impossible knowledge, critical ungrounded exposition with no carrier, and contradictions in time/object/location/knowledge state.

## Historical integrity

Attempts 1–5 keep their original recorded outcomes. No attempt is retroactively converted into a pass.

Phase 343 remains rejected under its old frozen 3/3 contract. Phase 344 supersedes that **promotion contract for future architecture work** because two labels are now shown to be context-dependent/contaminated as mandatory hard answers.

This is a benchmark correction, not a lowered pass threshold.

## Successor architecture requirements

The next architecture version should implement, but this calibration stage does not yet implement:

- explicit epistemic-scope fields in dialogue audits;
- separate `object fact` from `public knowledge / reported rumor`;
- preserve hard mouthpiece detection for genuinely reader-only shared setup;
- move portable-cadence repetition to manuscript-level pattern-family density evidence in G8/de-AI;
- retain local G6D failure for independently ungrounded critical dialogue;
- compare style-risk families across scenes/characters, not just one turn;
- preserve first-hand anecdote and relationship-specific banter.

No universal numeric density threshold is frozen in V1. The next implementation must gather evidence before selecting any threshold.
