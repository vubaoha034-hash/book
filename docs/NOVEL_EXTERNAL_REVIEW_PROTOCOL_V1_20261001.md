# 项目外小说评审协议 V1

依据：刘先生在2026-10-01明确要求由项目外的独立聊天承担小说日常审核，助手收回评价，并建立专业评审办法。此项只改变审核分工与局部修订触发方式，不更换《第二套过去》的方向、人物、七项事实或结局，不重写旧稿、旧锁与真人回执。

## 专业依据与适用范围

参考 Editors Canada 的结构编辑与叙事文体编辑标准，以及 CIEP 的小说编辑能力纲要。采用的是审查方法：按作品意图与读者判断结构、人物、视角、对白及连续性，最小改动并保护作者声音。手机第一屏留存和个人禁忌来自本项目实际反馈，并非上述机构规定的通用文学公式。

- [Editors Canada：结构编辑](https://editors.ca/publications/professional-editorial-standards/structural-editing/)：内容与组织应适合目标读者、媒介和目的；定位重复、缺口与可疑事实。
- [Editors Canada：叙事文体编辑 C1/C5](https://editors.ca/publications/professional-editorial-standards/stylistic-editing/)：核对实际阅读效果、情境与语言节奏；只改必要之处。
- [CIEP：小说编辑能力 3.1，PDF第38–39页](https://www.ciep.uk/asset/3927EFC9-256D-4660-9F4687833A2A2FA7/)：尊重创作意图；检查主题、情节、视角、对白和人物/时间/场景一致性。

短段只能检验第一屏与局部互动。整场才检验场景终点与因果；连段和全文才检验持续留存、人物弧线及主要情绪债/结局兑现。不得拿400字外审通过证明完整小说好看。当前没有已确认的同类安静关系正例，不能声称已学会个人文风。

## 分工与输入隔离

协调者冻结唯一正文、版本和范围后发送，取回评审，再负责修改与复审；刘先生无需替系统填表或审每轮失败稿。评审聊天在项目外，只审稿、不写稿、不改仓库、不另开执行者。

A轮先读匿名正文，仅知道题材、媒介与摘录位置。不给写作提示词、版本优劣、作者解释、已知真人判决或后文真相。首次用两份已知失败短稿作盲校准，与待审稿分别评估，锁定报告后再揭示对应反馈。

B轮在A报告冻结后接收必要故事契约、人物知识和事实、用户审美边界，完成编辑及连续性核对。它与A属于同一外部评审上下文的两阶段，不能宣传成两位独立读者。追加事实不能改写A轮真实记录。

此聊天复审修改稿时已经见过前稿与意见，必须标为“同一外审上下文复审”。重要交付若需要新的冷读，应另开项目外上下文；不能声称重复评审仍是初见。新聊天隔离了本项目对话，不保证账号记忆或模型训练来源完全隔离。结果是独立上下文的AI判断，不是真人行为数据。

## 六项审查与证据

| 项目 | 必须回答 | 不可混淆 |
|---|---|---|
| 留存与阅读承诺 | 前30–60字、150–300字和段尾，各产生了什么具体期待；在哪里滑读或停止，引用原句 | 有动作、有悬念标签不等于吸引；场景摘录不能被误当完整全书开篇 |
| 因果与动机 | 人物当下想做什么，哪句话/行动使其选择改变；更简单方案为何有成本 | 坐下、拿手机不自动等于有分量的转折；核验不等于认领 |
| 情绪与关系 | 谁向谁期待什么、哪里落空/改变；阅读情绪怎样变化；伤害、共情和兑现是否适合该人物 | 不强迫每段哭喊、反转或安插反派；表情不等于情绪兑现 |
| 节奏与场景功能 | 新信息、限制、选择、关系或代价改变了什么；删掉某段损失什么 | 短句、压缩和事件密度不自动等于好看 |
| 声音与对白 | 台词是否出于各自打算，是否可互换；信息问答、端正解释和伴奏动作具体在哪里伤害阅读 | “AI味”是可定位的表达问题，不能据此鉴定作者身份；不统一成同一种爆款口吻 |
| 事实与兑现 | 时间、金额、知情、物件、视角、世界规则和后续代价有无确定矛盾 | 未展示≠矛盾；没有全文不能判断结局已经兑现 |

每个意见包含：精确位置/短引文 → 根因 → 阅读或因果影响 → 修改目标 → 保护项 → 复验条件。每轮最多三个主要根因，不给总分，不堆禁词，不提供可直接替换的正文。能保护的有效部分也须定位。

## 判定与修订闭环

评审结论：EXTERNAL_PASS_PROVISIONAL / REVISE / BLOCKED / INSUFFICIENT。P0为确定逻辑/设定矛盾，P1为明显留存或人物/情绪失效，P2为局部表达问题。P0或P1未关闭不能过审；材料不足先核对材料，不通过虚构事实修补。

AI意见先经协调者核对：引文确实在该版本、事实争议属实、修改未触犯锁定内容。无证据或越界意见退回评审，不自动执行；既有真人否决不能被AI赞扬翻案。外审PASS仅允许有范围地继续制作，不等于真人认可或稳定文风。

日常流程：唯一版本冻结 → A/B评审 → 只修最高影响根因 → 冻结新版本 → 原评审按相同条件复验并查退步。单份稿最多连续两轮局部修订；仍无改善则回查故事输入/场景设计，保存失败，不无限堆规则，也不再把常规失败稿交给用户审核。主线目标、设定或结局的改变仍需用户明确改变范围；全文V5和旧关闭任务不自动重启。

当前新增授权允许用证据齐全的外审REVISE触发一次局部方法修订准备，无需把AI结果写成真人FAIL。旧方法4的真人结果继续UNKNOWN，后续另立修订锁与输入，不覆盖其正文/回执。用户只在过审的阶段成稿或影响方向/审美的关键决策时给简短反馈。AI判断与真人喜欢始终分别记录；缺少真人认可不能宣传已解决个人文风。

## 取回、保存与防漂移

完整任务一次填入、送出一次；前后比对正文与任务消息，不分段补发。固定稿件blob、协议hash、会话链接和原始报告hash。原始消息/完整浏览器快照留私有工作区，公开仓库只存必要协议、结构化结果、短证据及会话定位。

唯一仓库写作者是协调者；外审无写权限。提交前核对远端HEAD并非强制更新，完成后回读实际文件。协议、旧真人回执、作品保留项和校准结果随接管入口保存。校准仅检验能否发现已知负例，不证明不会误杀好稿；暂无匹配正例，假阳性与个人口味一致性尚未知。

这里是活动任务内的发送、读取和复审流程。没有设置后台定时任务，也没有声称两个聊天会在无人运行时自行互相推送。
