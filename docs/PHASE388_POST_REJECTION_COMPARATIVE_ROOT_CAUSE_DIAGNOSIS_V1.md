# PHASE388 — Phase387 真人拒绝后的对照根因诊断 V1

Status: COMPLETE DIAGNOSIS / NO FICTION GENERATED
Project: novel-distillation / 《一命过桥》
Highest accepted promotion checkpoint: Phase320（不变）

## 1. 证据边界

本诊断只比较以下已冻结证据：Phase387 fresh blind frozen output、Phase387 actual-human overall rejection、Phase368 A/B/C short-choice pack 与真人 B 选择、Phase369 selected-B span 与真人反馈、Phase370 motive-clarity repair 与真人反馈。

真人证据必须按原范围解释：
- Phase368：用户只明确说 B“有点悬念”；不是整体质量通过。
- Phase369：方向性评价更好、没有快进点、AI味更轻、确实想继续看；同时出现人物即时动机不够清楚的新 blocker。
- Phase370：即时动机清楚、剩余未知更像悬念、仍想继续看；AI味相对 Phase369 没有进一步下降；仍不是整体质量通过。
- Phase387：用户明确说整体仍不能过关。用户没有在这条反馈里分别结算 AI 味、继续阅读欲和具体停止点。

因此本报告中的“为什么”是 coordinator comparative diagnosis，不得伪装成用户亲口评价。

## 2. 最重要的新发现：Phase386 隔离做对了一半，也过度纠正了一半

Phase386 正确地把 Phase374/377/383/385 的诊断规则、AI味标签、读者驱动 beat、目标数量等从 writer 视野中移除，避免按规则施工。

但 Phase387 author packet 同时删掉了大量正常作者应该拥有的故事素材：人物长期关系史、主角具体脾气与习惯、顾承岳过去对刘还山形成的具体伤害/恩怨、可反复出现的熟人网络、地方生活与社会身份、已存在的人际债务、非技巧性的世界细节和人物私事。

writer 最终主要得到的是：刘还山、顾承岳、顾青禾的承诺、桥界法律规则、“顾承岳有罪但必须活着过桥”、当前路线选择。

这不是无污染的丰富故事上下文，而是一个极薄的道德命题加物流处境。

结论：HIDE DIAGNOSTICS != STARVE THE WRITER OF STORY LIFE。

## 3. ROOT-1 — AUTHORING CONTEXT STARVATION AFTER FIREWALL

这是当前最重要的流程根因。Phase386 为避免规则污染，把 writer 正常需要的丰富人物、关系、世界事实也一起删除。Astra 能把局部句子写得更自然，却没有足够具体的人物生活和关系资产可用。

## 4. ROOT-2 — CORE PREMISE REHEARSAL INSTEAD OF STORY-MODEL CHANGE

Phase387 中路人连续追问：你护着他？过了桥还护不护？这边抓不住，到了那边就抓得住？官府肯办他？那你凭什么拦我？

刘还山随后回答：我要送他过桥；过桥后不护；东岸官府才能接；不知道官府是否真办；因为答应了顾承岳的女儿。

这些内容基本就是 Phase387 author packet 已经提供给 writer 的核心故事契约。场景有冲突，但主要阅读回报是“已经知道的故事核心，被新路人重新问了一遍”。

Phase368–370 的局部正向段落虽然也没有整体过关，但至少持续改变当下故事模型：内部旧卒拔刀、异常木牌、身份记录不一致、街上人看见木牌后关窗、来箭压着木牌高度、顾承岳叫出陈长岭名字。读者需要重新判断当前到底发生了什么。

所以 Phase387 更接近 premise rehearsal，而不是高价值 story-model change。

## 5. ROOT-3 — DISPOSABLE MULTI-FUNCTION SIDE CHARACTER

Phase387 的挑担汉子在一千多字里同时承担：路线情报、识别顾承岳、提供顾承岳过去罪行案例、代表受害者家属、对刘还山进行伦理质问、发动冲突、迫使顾承岳表态、形成未来证人、可能报信、把路线推向官道。

现实人物当然可能同时有多个作用。问题在于，这个人几乎只为了完成这些作用而出现，完成后就离开。

当前 coordinator 标签：RC388-02_DISPOSABLE_MULTI_FUNCTION_MORAL_DEVICE。

对照 Phase368–370：陈长岭虽然也承担悬念功能，但他已经在护送群体内部，和霍九翁有旧营关系，弟弟与木牌会持续影响他的选择，他会继续同行。至少具备持续关系价值，而不是一次性主题触发器。

## 6. ROOT-4 — MORAL THEME EXPLICITLY LITIGATED

《一命过桥》的核心道德冲突本身有价值：为什么要保护一个可能应该受罚的人？

Phase387 直接让陌生受害者家属逐级把这个问题问出来。刘还山随后给出一套很完整的道德答辩：保护但不原谅、承认官府未必可靠、只因承诺、再要求顾承岳自己捡起被扫进泥里的银子。

风险不是主角不能有原则，而是场景过快替他完成道德辩护。人物因此更像伦理立场，而不是必须承担难看代价的人。

当前 coordinator 标签：RC388-03_PROTAGONIST_ETHICAL_POSITION_TOO_CLEANLY_AUTHORIZED。

## 7. ROOT-5 — LOW HIGH-VALUE MODEL DELTA

Phase387 结束后主要新增：顾承岳过去确实做过坏事；一个受害者家属恨他；河滩不好走；他们改走官道；这个人可能报信；前面有人注意他们。

这些信息大多属于原核心设定的例证、预期中的护送危险、路线困难升级。

它们没有明显重新定义顾承岳是谁、刘还山与顾承岳的关系、顾青禾的承诺真正意味着什么、当前敌我关系、谁值得信任，或下一步要追求什么新目标。

因此结尾“两个人一起朝这边望来”打开的是普通外部危险，而不是一个明显更高价值的新问题。

## 8. 生活细节为什么仍不够

Phase387 的靴中石子、破袜、冷泥、顾承岳拒绝被扶等细节，确实比很多旧稿自然。这说明 Phase386 的隔离并非完全无效。

但这些细节主要改善 prose surface，没有自动形成“我想跟这个人物待下去”“我想知道他们共同经历过什么”“我舍不得某段关系坏掉”等人物依恋。

结论：INCIDENTAL DETAIL != CHARACTER ATTACHMENT。

## 9. 为什么不能简单得出 Astra 不行

Phase387 至少出现局部自然度改善：物理细节不全是线索；顾承岳自己站起来、后来抽回胳膊，存在人物尊严与脾气；碎银被扫进泥里、刘还山让他自己捡，动作能承载关系态度；叙述者没有把每个心理含义全部讲透。

当前证据更支持：fresh isolation + Astra 可能改善局部 prose naturalness，但 author packet 太薄，无法支撑足够具体、足够值钱的故事场景。

一次被真人拒绝的 pilot 不能决定默认模型。

## 11. 不能从 Phase388 推出的东西

本诊断不证明：Phase370 是理想文风；木牌悬念应该复活；必须加入更多秘密或反转；每场都需要高密度谜团；Astra 已经胜出；Sol 不适合写小说；用户一定是因为上述五项中的某一项而拒绝 Phase387。

用户只明确给出了整体拒绝。上述根因是基于历史对照的 coordinator hypotheses，需要未来测试。

## 12. 下一步

不应立刻让 Astra 再写一版，也不应把 ROOT-1 到 ROOT-5 全塞给 writer。

下一阶段应该只修输入层：保持诊断防火墙，但给 fresh writer 一个更丰富的故事事实包，而不是技巧包。

这个 rich story packet 应包含：具体人物关系史、各自真实私利/羞耻/偏见/习惯、已发生且会影响当下行为的共同事件、可持续出现的人物网络、地方生活与身份事实、角色知道/不知道什么、当前处境。

仍然不能包含：AI味诊断、翻页机制、suspense beat、“要制造关系反转”等施工指令、真人失败答案键。

建议下一任务：PHASE389_RICH_STORY_CONTEXT_WITHOUT_DIAGNOSTIC_LEAKAGE_V1。
