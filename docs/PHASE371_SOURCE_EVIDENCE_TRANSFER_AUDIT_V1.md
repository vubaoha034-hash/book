## Audit question

Did the system genuinely distill the user's source novels, and did that distillation become reliable writing ability?

Allowed verdicts:
- REAL_EFFECTIVE
- PARTIALLY_EFFECTIVE
- UNPROVEN

The audit separates five layers. No earlier layer may substitute for a later one.

1. Source reality
2. Source-derived evidence trace
3. Distillation validity
4. Writing transfer
5. Scale transfer

---

## Executive verdict

The source novels were genuinely accessed and analyzed. This was not a fabricated or title-only distillation process.

However, the system did **not** successfully prove that the resulting Novel DNA / abstract rules became stable long-form writing ability.

The most accurate overall settlement is:

- SOURCE READING: REAL_EFFECTIVE
- SOURCE-DERIVED EVIDENCE: REAL_EFFECTIVE, with provenance durability defects
- BOOK-LEVEL DISTILLATION: PARTIALLY_EFFECTIVE
- CROSS-BOOK / GLOBAL DISTILLATION: PARTIALLY_EFFECTIVE AS STRUCTURAL KNOWLEDGE
- PROSE / READER-EXPERIENCE TRANSFER: PARTIALLY_EFFECTIVE
- GLOBAL DNA REAL-MANUSCRIPT WRITING TRANSFER: UNPROVEN
- LONG-FORM SCALE TRANSFER: NOT YET PROVEN

The main failure was not 'the books were never read'. The main failure was **knowledge-to-prose transfer**: abstract mechanisms survived, but the human-positive prose surface did not reliably survive long-form regeneration.

# Three-book microcraft distillation

## Source evidence — REAL_EFFECTIVE

The private `MICROCRAFT_SCENE_TO_SPEECH_EVIDENCE_V1` contains 30 source-derived samples for each of the three books.

The samples preserve:
- source location/scene identity
- scene state
- trigger
- perception/non-speech reaction
- why speech happens now
- speech function
- withheld/unsaid information
- aftereffect.

The resulting MC-C01–MC-C07 candidates are real evidence-derived microcraft, not invented without source text.

Examples of the abstracted mechanisms:
- dialogue needs an in-scene trigger
- non-response/silence can be information
- exposition needs an in-scene carrier
- question-answer ping-pong is not scene progress
- action beats must carry meaning rather than decorate every line.

## Transfer verdict — PARTIALLY_EFFECTIVE

These rules helped diagnose real problems in 《一命过桥》, but they did not prevent Phase364/Phase367 from becoming AI-like and unengaging for the actual target reader.

Phase363 short-form prose was human-positive. When that surface was abstracted into mechanisms and regenerated long-form, quality collapsed.

Later improvement returned only after the pipeline changed to:
- exact human-positive prose anchor
- A/B/C short choices
- actual-human selection
- one bounded span at a time
- actual-human review before additional growth.

Therefore source-derived microcraft knowledge is useful, but automatic scale transfer is not proven.

# Why the old system looked more successful than it was

1. It conflated `source analyzed` with `writing learned`.
2. It conflated `DNA validated structurally` with `prose quality proven`.
3. It over-relied on AI evaluators, which produced false-positive quality PASS against the actual target reader.
4. It allowed human-positive short prose to be reduced to abstract rules before scale-up.
5. It lacked a central durable source manifest even though private Drive evidence existed.
6. Global DNA was promoted for optional bounded production before any applied real-manuscript success existed; governance correctly kept it default-off, but later language sometimes implied more maturity than evidence supported.

# Remaining blocker

The system still lacks a three-book, source-anchored **reader-experience transfer layer** covering more than dialogue mechanics.

Required next evidence dimensions:
- hook / first-page propulsion
- pressure escalation and tension
- mystery vs confusion
- immediate motive legibility
- information-release timing
- character voice differentiation
- scene entry/exit energy
- pacing under continuous span growth
- emotional accumulation and payoff
- prose-surface anti-template behavior.

These must be extracted from real source spans with stable anchors and then tested in new prose using actual-human span-growth validation.

Until that exists, the project may claim:
`REAL SOURCE DISTILLATION EXISTS`

It may not claim:
`MATURE LONG-FORM WRITING ABILITY HAS BEEN DISTILLED`.
