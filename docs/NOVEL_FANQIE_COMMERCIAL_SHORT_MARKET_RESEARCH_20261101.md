## 4. 新的最小可执行生产链
0. **市场证据**：选5部最近30天在读上升的短故事，核对原作与前1000字、类别、实际字数、完结状态、第三方榜单采样时点。记录每部 `promise / character_desire / first_event / contradiction / first_choice / emotion_reward / gap_to_next`，不复制源文。
1. **商业故事种子（一份）**：固定目标读者、一级品类、15字以内的情绪承诺、一句冲突、与参考书不同的原创因果事件和个人独特经验；可先测试标题+200—500字钩子，不展开全书。
2. **人物选择**：先问主角为什么今天不退让、代价为何重要、为何有合理的对手；人物动作从利益而非“需要反转”逼出来。
3. **核心事件蓝图**：开篇人物命运已变化；每一次因果后果创造下一段值得看的问题；结尾兑现最初承诺，避免每500字自动反转的机械限制。
4. **正文生产**：独立writer只读事实、对立意图、必要限制、开篇期待；一次一版，按需分段，不对全篇直接使用大批风格禁令。需要的修改由编辑局部处理。
5. **真正的冷读**：匿名独立AI仅找读者的第一处疲劳/矛盾、明确不得给9分质量结论；用户真人若明确“没有续读”即拒绝，停止扩写，不坚持索取数字评分。
6. **可投稿门**：全文原创、排重/版权与内容合规、字数达标、章节/正文清晰、无重大事实冲突，稿件权限、账号实名认证、平台独家合同须由用户审核后再正式签约/投稿。成功文件存档与收益以实际平台后台/合同/支付入账为证。
