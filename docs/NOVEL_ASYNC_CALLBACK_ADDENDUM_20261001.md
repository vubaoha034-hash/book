# 小说逐轮主动回传补充协议

刘先生于2026-10-01明确要求：协调者发送任务后结束等待；项目外评审用Opera Neon完成审核后主动向指定协调聊天发送结果；协调者收到后继续处理并送审，不让用户转述。审核方保持聊天模式及极高思考（界面实际标签），不使用Pro替代。已授权的正常步骤不逐轮确认。

本补充只替代旧协议和D2中的外审禁止跨聊天发送、协调者轮询取回的传递限制。证据审稿职责、校准漏检、真人UNKNOWN、隔离写作、两轮局部修订预算和禁止自动全文晋级全部保留。旧协议、报告及锁不覆盖。

审核方仅向本补充绑定的协调会话主动回传；不写仓库、不调度其他执行者。每轮有唯一任务ID、回传ID、稿件blob和报告标识。完整消息发送前后逐字核对，发送一次；重复ID不重复执行。未确认发送先查实际消息，不盲目重发。陌生草稿不覆盖，活跃任务不点击停止，无法发送记录阻塞与未发送原文。

协调者送出任务并核对后结束本轮，不循环等待。外审在完成的同一轮调用Opera Neon回传，再结束本轮。收到新消息由协调者核对版本和最新仓库状态、保存证据、执行已授权下一步并送出新任务。回传到达、接收方启动、处理完成、下一轮派发分别验证，不用一条确认冒充整个创作闭环。

当前仅配置并测试链路，没有设置后台定时任务，不保证所有未来消息都能唤起执行。首次主动回传未到达前，状态必须为尚待实测；发送/触发失败时报告实际阻塞，不让用户承担常规转述。
