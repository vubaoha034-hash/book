# 《第二套过去》第二场起始短段

只写一份300–500字的小说正文，叙述贴近罗钧的所见、所想与未知。接在前场电话之后，写这次见面的起始短段；不必在这几百字里完成整场。

罗钧攒了多年首付，本来今天办完小公寓过户，晚上住进去。同一身份突然出现他毫无记忆的另一套三年经历，过户中止，30天冲突窗口刚开始。许澄来电问过户是否停了。他问是否认识，她说：“你现在是不认识。”他们现在在大厅外公共休息区见面。

罗钧眼里她是陌生人。他急着让买房继续，担心接下她说的过去就得把自己的钱也交出去。他可以查证，尚不能认领责任，也没有恢复记忆。

许澄记得两人共同生活、经营摄影工作室和签设备款协议的经历。旧工作室已停业；她如今独立接摄影后期，明天下午前要用留出的1.2万元交新工作间押金。旧设备款还剩18.6万元，其中6.8万元五天后到期。若要她先独自筹，押金预算也会受影响，填进去还差5.6万元。她不能无限期替两个人垫付，要知道他会为核验投入什么时间，好安排自己的钱和业务；她不要求他假装记得她。

她带有合同复本。供应商另外留存合同和收款记录，可由他自行找到的公开联系方式核验，来源不受她控制。工作室停业没有取消欠款，两人都还不知道另一套过去的来源。

完整场景最终将形成有限核验合作：独立来源得到初步吻合，他尚不认领，她配合有边界，旧关系不恢复。这是以后完整场景的终点，起始短段不用赶到这里。
