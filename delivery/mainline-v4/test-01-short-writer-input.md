# 《第二套过去》第二场起始短段

写一份300–500字小说正文，贴近罗钧的限知视角。两人在过户大厅外公共休息区第一次当面相见。选择相反打算已经碰上的时刻进入，让这次交谈影响一个眼前安排；不用交代完整到场过程，也不用完成整场。

罗钧攒了多年首付，本来今天完成小公寓过户，晚上住进去。同一身份突然多出他毫无记忆的另一套三年经历，过户中止，30天冲突窗口刚开始。前场许澄来电问过户是否停了；他问是否认识，她说：“你现在是不认识。”

他想先结束这次谈话回大厅争取房子，认为把材料留下、等查清再谈责任便是公平的。眼前女人在他看来是陌生人；他怕接下她说的过去就得交出多年积蓄，守住自己的钱使他很难听进她的处境。他可以查证，但不能恢复记忆、假装亲近或提前认领。

许澄记得共同生活、经营摄影工作室和签设备款协议的三年。她明知他不记得，见到熟悉的人仍残留熟悉期待，被当成来碰首付的陌生讨款者会触及她的经历和尊严。她不逼他假装记得，也不愿为了体谅他把共同责任吞下。她有自己的后期业务要做，能给这次协助的时间有限；他把事情推后，不能当然要求她随时解释、安排和等待。她可以限定配合时间，但不扣住独立证据或阻挡他自行查证。

旧工作室已停业，设备款剩18.6万元，其中6.8万元五天后到期。许澄留了1.2万元，明天下午要交自己新工作间的押金；这笔预算可能被筹旧款挤掉，其他资产未知。她带合同复本，供应商另有合同和收款留存，可由罗钧自己找到的公开联系方式核验。停业没有取消欠款，两人都不知道另一套过去的来源。

完整场景最终只到独立来源初步吻合后的有限核验合作，他仍不认领，她配合有边界，旧关系不恢复。短段可以只写这次相撞及由此改变的当前安排，不必覆盖所有金额和核验手续；不提前写正式追偿、全面退出配合或公寓不可逆损失。
