# 《第二套过去》第二场写作输入

写一份完整的第二场小说正文。叙述贴近罗钧的所见、所想与未知，人物的说话、行动及其先后由你决定。正文从前场电话之后衔接，写到下述终点为止。

## 前场结尾

罗钧攒了多年首付，本来今天要办完小公寓过户，晚上住进去。办理时，同一身份出现一套他完全不记得的三年责任记录，过户中止，30天身份冲突窗口启动。原来的三年证据仍在。异常单上的另一位当事人叫许澄。

许澄来电问过户是不是停了。罗钧问两人是否认识，她回答：“你现在是不认识。”本场接在这次电话之后。

## 七项固定事实

1. 小公寓过户已经中止，场景仍在30天冲突窗口早段。
2. 罗钧没有第二过去的主观记忆，没有恢复记忆，也没有默认旧关系成立。
3. 许澄经历并记得第二过去中的共同生活与共同责任；她不能替罗钧认领责任。
4. 许澄不是唯一证据源，有与她控制范围分离的独立核验路径。
5. 共同责任早于30天终点到期；许澄不接受无限期成为唯一现实承受者。
6. 罗钧本场可以核验事实，但尚不认领共同责任。
7. 终点是两个独立当事人的有限合作，旧关系不恢复。

## 此刻的两个人

罗钧刚失去今天拿钥匙的确定性。他想查出哪里出了错，继续完成自己的买房计划；许澄在他眼里仍是陌生人。他怕一旦把她的材料和她说的过去接下来，钱和身份也被一并接管。他能核验，尚不能承诺。

许澄记得那三年，记得两个人一起经营小型摄影工作室、一起签下设备款协议。那个工作室后来已停业。如今她独立接摄影后期工作，准备租一个小工作间，继续自己的业务。她知道眼前这个人没有她的记忆，也无法确定他是做不到相信，还是准备一直拖下去。她要保住现在的生活和共同责任中的权利。

## 眼前的生活事实

过户中止当天，第一次电话之后，两人在大厅外的公共休息区见面。

旧工作室的灯具和摄影设备分期款还剩18.6万元，其中6.8万元在五天后到期。协议记载两人为共同付款义务人。许澄手里有合同复本；设备供应商独立留存的合同及收款记录，能经罗钧自行找到的公开联系方式或过户告知单提供的核验路径查证。核验不需要信任许澄的设备或查询页面。本场只需出现足以让怀疑发生变化的初步跨源吻合，完整的多源真实性结论还在后面。

许澄原本要在明天下午前交1.2万元押金，订下已经看好的小工作间。那是她自己继续接活的安排。若旧款要她先独自筹，押金预算也会被占用；这1.2万元也远不够付清6.8万元。此刻是她的安排受到威胁，尚未提前发生后来的正式追偿。她如何处理这个风险，由本场人物互动形成。

旧工作室停业没有取消设备款。罗钧的责任尚处身份争议，许澄在该记录中的身份没有争议；付款期限不会等调查结束。两人此时都不知道第二过去的来源。普通证据保全只能保存记录，长期保护第二套历史仍需当事人在其中有当前可执行的权利或义务；这个区别只在影响本场选择时自然进入。

## 场景终点

双方确认至少一组材料有许澄控制以外的留存来源。罗钧愿意继续核验、保全记录，尚不认领责任。许澄暂时合作，但不接受无限期独自垫付，也不要求他伪装记得她。此后还要进一步查证，房子的交割压力仍在。

## 行文基线

让读者知道这两个人此刻各自想保住什么。叙述、心理、对白、动作以及长短句可以按场景自然组合，允许没说透的感受和不整齐的反应。人物有自己的事情可关心；信息进入他们正在处理的生活。采用本故事自己的叙述声音，不模仿具体作者。这个场景没有已验证适配的成篇文风样本。
