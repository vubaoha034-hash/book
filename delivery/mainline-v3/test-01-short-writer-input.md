# 《第二套过去》第二场起始短段

只写一份300–500字的小说正文。接在前场电话之后，从两人第一次当面相见写起，不必完成整场。叙述贴近罗钧的所见、所想与未知，许澄的内心通过他能看到、听到和理解的部分呈现。

罗钧攒了多年首付，本来今天办完小公寓过户，晚上住进去。同一身份突然出现他毫无记忆的另一套三年经历，过户中止，30天冲突窗口刚开始。许澄来电问过户是否停了。他问是否认识，她说：“你现在是不认识。”两人在大厅外公共休息区见面。

罗钧眼里她是陌生人。他急着回去争取房子，怕接下她说的过去就得把多年积蓄交出去。他觉得先查清再谈责任是公平的，想先挡住这件事，尚没把她的等待当成真实损失。他不是故意来伤她，但守住自己的钱会使他很难听进她的处境。他可以查证，尚不能认领责任，没有恢复记忆。

许澄记得两人共同生活、经营摄影工作室和签设备款协议的三年。她来前已知道他不记得，见到熟悉的人仍带着一点未撤掉的熟悉期待。他防着一个陌生讨款者时，她面对的却是共同生活过的人把自己挡在外面。她不愿被当成来拿首付的骗子，也不能为了体谅他把两个人的到期款都吞下；她不要求他假装记得，不以旧关系强迫他承认。

旧摄影工作室已停业，设备款剩18.6万元，其中6.8万元五天后到期。许澄现在独立接摄影后期，明天下午要用留出的1.2万元交自己的新工作间押金。独自筹旧款会挤掉这个安排，押金填进去仍差5.6万元；她还有哪些资产未知。她要安排自己的钱和业务，不接受无限期替两个人垫付。

她带合同复本。供应商另有合同和收款留存，罗钧能自己找到公开联系方式核验，来源不受她控制。停业没有取消欠款，两人都不知道另一套过去的来源。

本场最终只形成独立证据初步吻合后的有限核验合作：他仍不认领责任，她配合有边界，旧关系不恢复。起始短段无需赶到终点，也不用交代所有金额或核验步骤。
