# 《第二套过去》第二场起始短段

局部修订下面的现有短段，最终只返回一份300–500字小说正文，贴近罗钧的限知视角。两人在过户大厅外公共休息区第一次当面相见。不用交代完整到场过程，也不用完成整场。

罗钧攒了多年首付，本来今天完成小公寓过户，晚上住进去。同一身份突然多出他毫无记忆的另一套三年经历，过户中止，30天冲突窗口刚开始。前场许澄来电问过户是否停了；他问是否认识，她说：“你现在是不认识。”

他想先结束这次谈话回大厅争取房子，认为把材料留下、等查清再谈责任便是公平的。眼前女人在他看来是陌生人；他怕接下她说的过去就得交出多年积蓄，守住自己的钱使他很难听进她的处境。他可以查证，但不能恢复记忆、假装亲近或提前认领。

许澄记得共同生活、经营摄影工作室和签设备款协议的三年。她明知他不记得，见到熟悉的人仍残留熟悉期待。她不逼他假装记得，也不愿为了体谅他把共同责任吞下。她有自己的后期业务要做，能给这次协助的时间有限。她可以限定配合时间，但不扣住独立证据或阻挡他自行查证。

旧工作室已停业，设备款剩18.6万元，其中6.8万元五天后到期。许澄留了1.2万元，明天下午要交自己新工作间的押金；这笔预算可能被筹旧款挤掉，其他资产未知。她带合同复本，供应商另有合同和收款留存，可由罗钧自己找到的公开联系方式核验。停业没有取消欠款，两人都不知道另一套过去的来源。

## 当前底稿

“材料我带走，等查清了再说。”罗钧把购房文件袋夹到腋下，椅脚在公共休息区的地砖上刮了一声。

许澄叫了声“罗钧”，声音比电话里软。他以为她要拦，先看向大厅入口。

“窗口还没关。我总得问问房子。”

她的目光落到文件袋上。他把袋口压紧：“我不认识你。我的首付——”

“我没让你转钱。”她原来向他倾着的上身慢慢坐直，“也没让你装作认识我。”

他想说材料已经收了，总不能连查清的时间都不给。

“我三点就得走，要赶客户的片子。”她看了眼表，“五天后有款到期。你今天不查，可以另外安排。但你不能说一句以后再谈，就让我一直等着。”

罗钧跟着看表，还剩二十分钟。他本来打算把复本塞进文件袋最底下，回去再翻。攒首付的时候，他连今晚住进去以后先做什么都想过，没想过要给一个陌生女人留出时间。

他仍站着，问：“供应商叫什么？电话我自己找。”

许澄把合同转过来，指了指封面，没替他念。

大厅里有人叫号。他听完，叫的不是自己，便把椅子拉回来，坐下掏出手机。
