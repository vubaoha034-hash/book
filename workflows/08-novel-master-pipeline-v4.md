# Novel Master Pipeline V4 — Reader-Compulsion Architecture

## Why V4 exists

V3 can prove causality, continuity, dialogue grounding and de-AI constraints while still allowing a manuscript that is correct but dramatically flat. V4 therefore makes reader propulsion and scene experience first-class acceptance evidence.

V4 inherits V3; it does not erase or reinterpret historical V3 results.

## Mandatory source layer

Read:

- `library/reader-experience-technique-bank.v1.md`
- `rules/reader-reward-rhythm.md`
- `rules/suspense-reversal-payoff.md`

Novel DNA remains optional/default OFF. Reader-experience techniques are not Novel DNA and do not require DNA Router invocation.

## Phase order

### Phase A — Story and causal contract

Run existing V3 story contract, causal proof, emotion debt, continuity and character pressure checks.

### Phase B — Entry/return causality

Run `modules/scene-entry-motivation.md` on every material entrance, re-entry, withdrawal reversal or role switch.

A character may not appear because the author needs a rescuer, witness, explainer or emotional beat.

### Phase C — Reader propulsion map

Run `modules/reader-propulsion-ledger.md` scene by scene.

For each material scene, record both:
1. story-state change;
2. reader-state change: what the reader now wants, fears, expects or needs answered.

A scene with event progress but no stronger reader desire is not automatically acceptable.

### Phase D — Suspense hypothesis engine

For every mystery carried across scenes, run `modules/suspense-hypothesis-engine.md`.

Required: lock, stake, current reader model, fair evidence, competing/wrong model when supported, residual anomaly, next verification action, cost, model update and next lock.

A repeated strange object plus later explanation is not a suspense engine.

### Phase E — Emotional staging

Run `modules/emotional-staging-ledger.md` on high-emotion and high-relationship scenes before line polishing.

Important dialogue must be earned by pressure, conflicting wants, behavior/subtext and aftershock. Short dialogue is allowed; skeletal dramatization is not.

### Phase F — Natural speech under pressure

Run legacy G6D plus `modules/natural-speech-pressure.md`.

Two separate questions are mandatory:
- Is the line true/motivated?
- Would this person package the information this way now?

Do not repair author-summary speech with particles, slang or generic gestures.

### Phase G — Climax escalation curve

Run `modules/climax-escalation-curve.md` on every major climax.

Escalation must narrow meaningful options, raise personal stakes, reactivate prior assets/relationships, force an irreversible choice and leave payoff/aftershock.

More enemies, attacks and explanations do not equal escalation.

### Phase H — Legacy integrity and de-AI

Run all applicable V3 G6D/G8 checks. Preserve calibrated false-positive controls.

G6D/G8 PASS is necessary but not sufficient.

### Phase I — Fresh immersion reader

This is mandatory before final freeze.

The fresh reader receives only the bound manuscript and the V4 reader protocol, not repair history or expected answers.

Required evidence:
- exact points where they wanted to continue and why;
- exact points where attention dropped, skimming began or reading would stop;
- active suspense hypotheses they actually formed before reveals;
- emotional scenes that were experienced versus merely understood;
- dialogue that sounded spoken versus written/briefed;
- whether climax pressure genuinely rose rather than merely accumulated events.

A checklist-only audit cannot substitute for this pass.

### Phase J — Final freeze

Final freeze requires:
- applicable V3 gates PASS;
- V4-G1M PASS;
- V4-G5R PASS;
- V4-G5S PASS when material suspense exists;
- V4-G5E PASS;
- V4-G6N PASS;
- V4-G7C PASS;
- V4-G9 fresh immersion PASS;
- no unresolved blocker/HOLD that affects delivery quality.

## Hard governance rule

Never again infer `ready_to_freeze = G6D_PASS && G8_PASS`.

The correct relation is:

`ready_to_freeze = legacy_integrity_pass && reader_propulsion_pass && suspense_pass_if_applicable && emotional_staging_pass && natural_speech_pass && climax_pass && fresh_immersion_reader_pass`.

## Rewrite discipline

When an existing manuscript fails V4, fix upstream reader-experience architecture before polishing individual sentences. Do not repeatedly edit five lines until a narrow evaluator passes while the manuscript-wide reading experience remains weak.
