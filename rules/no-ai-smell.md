# 去 AI 腔终审规则

## 使用边界

只在主线、因果、人物选择、情绪兑现、连续性和 V3-G6D 已稳定后运行。默认做终审和最小修改，每轮最多处理五个高影响模式。

去 AI 不能救坏故事，也不能保证绕过任何平台检测。

## AI 腔的主要来源

### 1. 过度解释

动作、台词或物件已经让读者看懂，后面又解释情绪、立场和意义。优先测试删掉段尾解释后是否更有力。

### 2. 平均正确

每个人都得体、完整、会总结；每段长度相似；每场都用相同方式冲突和收尾。保留符合处境的误解、嘴硬、算计、逃避和不完整表达。

### 3. 通用情绪动作

警惕批量出现：手指收紧、深吸一口气、眼神复杂、嘴角勾起、心口一沉、转身没有回头等。动作不属于这个人物/压力、也不改变读法时直接删，不换另一组万能动作。

### 4. 物件堆砌

具体物件只有在暴露人物、推进情节、加重冲突、提供/回收线索、改变关系权力或承载个人化情绪等方面有真实作用时才突出。

### 5. 说明书式对白

G6D 已先处理局部真值。G8 不得重新把“听者知道 X”简单当成嘴替证据。

先区分：

```text
听者知道 X
听者知道外界也知道 X
传闻具体怎么说 X
外界因知道 X 已经采取什么行动
```

如果对白有新的公开知识/暴露/风险 payload，但表达过度完整，这里只处理冗余和自然度，不把它伪装成新的逻辑硬错。

### 6. 假高级与意义尾巴

警惕命运、宿命、光影、破碎、仿佛、某种，以及“这一刻他终于明白”“真正重要的不是”等重复总结。不是机械禁词，只删除替读者完成理解的部分。

### 7. 节奏被剪成电报

快节奏来自局势变化和人物选择，不是通篇短句、断行和删除心理。高潮可短，复杂判断可长，情绪兑现后允许余波。

### 8. 人物声音趋同

检查年龄、职业、阶层、关系亲疏和压力如何改变词汇、句长、回避方式与攻击方式。不要把所有人改成同一种“自然口语”。

### 9. 跨场景对白模板族密度

读取：

```text
modules/dialogue-pattern-family-density.md
templates/dialogue-pattern-family-audit-template.md
```

不要逐句猎杀笑话。先把局部已经通过/未定的可移植节拍按**功能和 cadence**聚类，例如：

```text
问 → 机灵反问 → 被诱导追问 → 包袱
问 → 连续回避 → 最后才说真话
陈述 → 讥讽纠正 → 再纠正 → 尾句
```

真正高风险的是：

- 相隔很远的场景重复同一结构；
- 不同人物/关系都使用几乎相同节奏；
- 很少依赖当前物件、任务、旧账或身份；
- 笑点可以平移给无关人物；
- reveal timing、应答策略和句子节奏持续同质化；
- 结果是“所有人物都像同一个模型在说话”。

使用风险码：

`DIALOGUE_TEMPLATE_FAMILY_DENSITY_RISK`

**单个可删笑话不是 density 证据。**

**幽默多也不是 density 证据。**

当前三书证据不足以支持统一数字阈值，因此禁止规定“出现 N 次就失败”。

同一个人物的固定口头习惯、running joke、仪式性问答或关系内部暗号，有正文支持时可以保留。

## 终审方法

1. 读取认可样本、拒绝样本和审美基线；样本为空则说明限制。
2. 先识别全文最反复、最伤读感的 2—5 个模式，而不是逐句找错。
3. 对对白模式建立 pattern-family ledger：实例、场景、人物、关系、cadence、特异性、可移植性、后果。
4. 区分局部 G6D 真值问题与 G8 全文密度问题。
5. 对高风险 family，保留最具体、最属于人物的实例，优先删/改最通用的重复实例。
6. 修改后复核情节事实、人物知识、时间、关系和规则未变化；改动对白再做局部 G6D。

## 禁止事项

- 不把所有心理改成动作。
- 不把所有抽象词改成物件。
- 不把所有句子改短。
- 不故意制造错别字、病句和随机口语。
- 不承诺 AI 检测百分比。
- 不用润色掩盖结构、逻辑和情绪债问题。
- 不把一个 locally plausible/removable joke 直接判成全文模板污染。
- 不用固定次数阈值替代 pattern-family 证据。
