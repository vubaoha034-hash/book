# Global Reader Reward Rhythm

用于沉淀读者奖励节拍：爽点、悬念、情绪补偿、认知爽、羞辱点、危机点、争议点。

## 写入格式

```text
奖励类型：
前置压迫：
释放方式：
读者获得什么：
主角付出什么成本：
下一步制造什么问题：
适合平台：短视频 / 短剧 / 公众号短小说 / 长篇网文
原创例子：
```

## 默认节拍目标

- 短视频/短剧：30–90 秒有小奖励，3–5 分钟有大转折或大爽点。
- 公众号短小说：300–600 字有小奖励，1200–2000 字有大反转或强情绪释放。
- 长篇章节：每小节有推进，每章有奖励，章末有新问题。

这不是死规则，是检测“读者多久没得到东西”的工具。
